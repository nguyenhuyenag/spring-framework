# Spring Boot Test

## Test scope dependencies trong Spring Boot

1. JUnit 5: Vai trò:
   - Cung cấp annotation @Test, @BeforeEach, @AfterEach, @BeforeAll, @AfterAll, @Disabled, v.v.
   - Quản lý vòng đời của bài test (lifecycle).
   - Tích hợp với các runner và extension của Spring.

2. Spring Test & Spring Boot Test: @SpringBootTest`, `@WebMvcTest`, `@DataJpaTest`

3. AssertJ: A fluent assertion library.

4. Hamcrest: A library of matcher objects (also known as constraints or predicates).

5. Mockito: A Java mocking framework.

6. JSONassert: An assertion library for JSON.

7. JsonPath: XPath for JSON.

8. Awaitility: A library for testing asynchronous systems.
